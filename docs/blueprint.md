# **App Name**: VisionAttend

## Core Features:

- Secure User Enrollment: Allows administrators to securely enroll new users and capture their facial data for future identification. Includes robust profile management.
- AI-Powered Attendance Marking: Enables users to mark their attendance effortlessly through real-time facial recognition. The system uses AI as a tool to process and verify facial features against enrolled profiles.
- Real-time Attendance Dashboard: Provides administrators with a real-time overview of attendance status, latecomers, and absentees, updated instantly from Firestore.
- Role-Based Access Control: Implements distinct permission levels for different user roles (e.g., students/employees, administrators) to ensure data security and prevent unauthorized access.
- Comprehensive Reporting & Analytics: Generates detailed attendance reports based on various criteria, offering insights and facilitating data-driven decision-making.

## Style Guidelines:

- Light color scheme, prioritizing clarity and professionalism.
- Primary color: A sophisticated, deep blue (#195DE5), symbolizing trust and efficiency. Chosen for its calm and professional resonance, steering clear of literal, uninspired interpretations often associated with technology.
- Background color: A subtle, light blue-grey (#F0F2F4), providing a clean and non-distracting canvas, harmoniously desaturated from the primary hue.
- Accent color: A vibrant sky blue (#47B3EB), selected as an analogous contrast to the primary blue, ensuring important UI elements stand out while maintaining a coherent aesthetic.
- Body and headline font: 'Inter' (sans-serif) for its modern, clean, and highly readable characteristics, perfectly suited for a tech-focused application.
- Minimalist and modern line-art icons that complement the clean interface, focusing on functionality and clarity for easy understanding.
- Clean, spacious layout with a clear hierarchy of information to guide users efficiently, using a responsive grid system for optimal viewing across devices.
